# Линейная шкала — DRO для токарного станка

Двухконтроллерная система цифровой индикации (DRO) для токарного станка.

## Архитектура

```
Reader ESP32                     Display ESP32-S3 (Waveshare 7")
┌─────────────────┐   I2C (25Hz)  ┌─────────────────────────┐
│ PCNT → шкала A/B│─────────────→│ LVGL UI 800×480         │
│ 10 кнопок GPIO  │  pos + btns  │ Тачскрин + кнопки       │
│ Энкодер (опц.)  │              │ 2 оси: радиальная/осевая│
│ I2C slave 0x20  │              │ I2C master bus 1        │
└─────────────────┘              └─────────────────────────┘
```

## Сборка

Требования: ESP-IDF v5.1+

### Reader (ESP32)

```bash
cd reader_fw
idf.py set-target esp32
idf.py build
idf.py -p /dev/ttyUSB0 flash
```

### Display (ESP32-S3)

```bash
cd display_fw
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/ttyUSB1 flash
```

## Назначение пинов

### Reader ESP32

| Пин | Назначение |
|-----|-----------|
| GPIO4 | Шкала A |
| GPIO5 | Шкала B |
| GPIO12-15 | Кнопки Т1–Т4 (радиальная ось) |
| GPIO16-18,21 | Кнопки Т1–Т4 (осевая ось) |
| GPIO22 | Кнопка D/R toggle |
| GPIO23 | Резервная кнопка |
| GPIO26 | I2C SDA (slave) |
| GPIO27 | I2C SCL (slave) |

### Display ESP32-S3

| Пин | Назначение |
|-----|-----------|
| GPIO0–48 | LCD RGB (см. waveshare_rgb_lcd_port.h) |
| GPIO8,9 | I2C bus 0 — тачскрин GT911 + CH422G |
| GPIO43 | I2C bus 1 SDA → Reader |
| GPIO44 | I2C bus 1 SCL → Reader |

## Протокол I2C

Display (master) опрашивает Reader (slave, адрес 0x20) с частотой ~25 Гц.

Пакет ответа (8 байт):

| Смещение | Поле |
|----------|------|
| 0 | Версия протокола (0x01) |
| 1 | Состояние кнопок (младший байт) |
| 2 | Состояние кнопок (старший байт) |
| 3–6 | Позиция, int32 LE (единицы: 0.005 мм) |
| 7 | CRC-8 (XOR байт 0–6) |

Биты кнопок:

| Бит | Кнопка |
|-----|--------|
| 0–3 | Т1–Т4 радиальная ось |
| 4–7 | Т1–Т4 осевая ось |
| 8 | D/R toggle |
| 9 | Энкодер (зарезервировано) |

## UI

Экран разделён вертикально:
- **Левая половина** — радиальная ось (радиус/диаметр)
- **Правая половина** — осевая ось (длина)

Каждая половина содержит:
- Главную нулевую точку отсчёта (крупно)
- 4 дополнительных точки Т1–Т4
- Кнопку «Обнулить» для главной точки (с подтверждением)
- Кнопки «0» для каждой дополнительной точки

Радиальная ось дополнительно:
- Кнопка D/R — переключение радиус/диаметр (для всех точек)
- Поле ввода диаметра — оператор измеряет микрометром и вводит значение

## Шрифт с кириллицей

По умолчанию UI содержит русский текст, но встроенный шрифт Montserrat
не поддерживает кириллицу. Для корректного отображения:

1. Перейти на https://lvgl.io/tools/fontconverter
2. Выбрать шрифт с кириллицей (Roboto, Montserrat Cyrillic)
3. Размеры: 12, 16, 20, 24, 48
4. Символы: `абвгдеёжзийклмнопрстуфхчшщъыьэюяАБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ0123456789+-.`
5. Скачать .c файлы
6. Добавить в `display_fw/main/` и обновить `CMakeLists.txt`
7. Обновить ссылки на шрифты в `ui_styles.c`
